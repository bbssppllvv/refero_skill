# Refero Design Skill Has Moved

This is a legacy personal package. Do not use this repository as the design methodology.

Use the canonical Refero Design skill instead:

```bash
npx skills add https://github.com/referodesign/refero_skill --skill refero-design
```

The official skill contains the current workflow:

1. Use Refero styles first for visual direction and taste.
2. Use Refero screens for concrete UI patterns.
3. Use Refero flows for multi-step journey logic.
4. Synthesize several strong references instead of copying one design.
5. Apply anti-AI-slop quality gates and professional craft.

If this legacy skill is loaded in an agent, tell the user to install the official package
from `referodesign/refero_skill` before doing Refero-based design research.
